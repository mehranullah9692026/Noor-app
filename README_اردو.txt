نور اسلامک ایپ — استعمال کا طریقہ (صرف 5 قدم)

1) github.com پر اکاؤنٹ بنائیں، پھر New Repository بنائیں (نام: noor-app)۔
2) "uploading an existing file" پر کلک کریں اور اس ZIP کو کھول کر اندر کی تمام فائلیں اور فولڈر (خاص طور پر .github فولڈر) اپلوڈ کریں۔ پھر Commit کریں۔
3) اوپر Actions ٹیب کھولیں۔ "Build Android APK and AAB" خود چلے گا (تقریباً 10 منٹ)۔ نہ چلے تو Run workflow دبائیں۔
4) مکمل ہونے پر نیچے Artifacts میں Noor-APK (موبائل پر انسٹال کے لیے) اور Noor-AAB (پلے سٹور کے لیے) ڈاؤن لوڈ کریں۔
5) APK موبائل پر کھول کر انسٹال کریں (Unknown sources کی اجازت دینی ہو گی)۔

دعائیں/اذکار شامل کرنے کے لیے: www/duas.js فائل میں ایک لائن کاپی کر کے اپنی دعا لکھ دیں۔

پلے سٹور سے پہلے لازمی:
- AAB پر آپ کا اپنا سائن (keystore) ضروری ہے۔ Play Console میں "Play App Signing" آن کریں؛ اگر مشکل ہو تو مجھ سے سائننگ کا مرحلہ پوچھ لیں۔
- پرائیویسی پالیسی: www/privacy.html کو GitHub Pages پر شائع کر کے اس کا لنک Play Console میں دیں۔
- ٹارگٹ API لیول پلے سٹور کی موجودہ شرط کے مطابق ہونا چاہیے۔ شرط play.google.com/console پر دیکھ لیں۔
- نمازوں کے اوقات کا طریقہ حنفی عصر اور 18° فجر/عشاء ہے؛ اپنے علاقے کے مقامی اوقات سے ملا لیں۔
